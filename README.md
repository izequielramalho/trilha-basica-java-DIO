# Sintaxe Java - DIO Orange Tech+ Backend

Repositório criado durante o bootcamp Orange Tech+ Backend da DIO,
documentando meu aprendizado sobre a sintaxe da linguagem Java.

## Conteúdo

- **Anatomia das Classes** → estrutura completa de uma classe Java
- **Tipos e Variáveis** → tipos primitivos e não primitivos
- **Operadores** → aritméticos, relacionais, lógicos e unários
- **Métodos** → void, retorno, parâmetros e passagem de dados
- **Escopo** → limite de acesso de variáveis e atributos
- **Palavras Reservadas** → palavras que pertencem à linguagem Java
- **JavaDoc** → documentação oficial do código
- **Scanner** → leitura de dados digitados pelo usuário em tempo real
- **Argumentos** → passagem de dados via terminal antes da execução
- **Exemplo de Método** → exemplos práticos com SmartTv e Usuario

## Tecnologias
- Java 17
- IntelliJ IDEA
- Git e GitHub
- Terminal
